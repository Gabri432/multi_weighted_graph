# MultiWeightedGraph

- A class representing graphs having multiple weights associated to each edge.

## Project structure
```
- multi_weighted_graph (root)
    - license
    - README.md
    - .gitignore
    - pyproject.toml
    - src/multi_weighted_graph (folder)
        - __init__.py
        - _core.py
        - _utils.py
        - py.typed
    - tests (folder)
        - test_core.py
```

## Tech stack

- Python 3.14.3
- pytest 9.1.1
